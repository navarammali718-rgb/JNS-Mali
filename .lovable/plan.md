# Complete household-products storefront

## Build
- Create a cohesive Indian household essentials brand with a bright, practical ecommerce design system, product-led imagery, responsive navigation, and mobile shopping controls.
- Add realistic mock catalog data for scrubbers, brushes, loofahs, camphor, and utility products, with rupee pricing, ratings, discounts, pack sizes, and wholesale tiers.
- Implement shared frontend state for search, filters, wishlist, cart quantities, checkout steps, and account/order views using in-memory mock data only.

## Pages and flows
- Homepage with search, category discovery, offers, featured products, bulk-buy callout, trust information, and product recommendations.
- Shop and category browsing with sorting, filters, search results, empty states, and product cards.
- Product detail pages with gallery, variants, delivery estimate, quantity, bulk pricing, reviews, related products, wishlist, and cart actions.
- Wholesale page with tiered pricing and a bulk-order builder.
- Cart, checkout, and order confirmation with simulated address, delivery, and payment selections.
- Account dashboard, orders, tracking timeline, and wishlist.
- About, contact, FAQ/help, shipping, returns, and privacy pages.

## Quality checks
- Add unique page metadata, semantic structure, accessible controls, responsive layouts, and reduced-motion behavior.
- Verify the main browse-to-checkout flow and key mobile/desktop screens in the running preview.
