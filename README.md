# Sparkle & Shine Store

Create a complete, polished customer-facing frontend for a modern online store that sells affordable household and cleaning utility products. The products include kitchen scrubbers, stainless-steel scrubbers, scouring pads, cleaning brushes, bath scrubbers, loofahs, nylon rope bath brushes, household utility products, camphor and similar everyday-use items. The overall design should feel like a modern, well-organized Indian household-products wholesale/retail store. Keep it practical, approachable, colorful and trustworthy. The products should be the visual focus. Use a clean commercial ecommerce aesthetic rather than a futuristic, sci-fi, luxury, or overly minimal style. You have creative freedom to decide the exact visual style, layout, typography, color palette, component design, animations and user experience. Make your own design decisions based on the nature of these products. Include the complete customer-facing experience with: - Homepage - Shop/products page - Category pages - Product detail pages - Search and filtering - Wholesale/bulk shopping experience - Cart - Checkout - Order confirmation - Customer account - Orders/order tracking - Wishlist - About - Contact - FAQ/help - Footer and other necessary supporting pages Make the website fully responsive for desktop, tablet and mobile. Use realistic mock product data and images/placeholders where necessary so the frontend feels complete and functional. IMPORTANT: This is strictly a frontend-only project. Do NOT create or implement any backend, database, API, server-side logic, authentication backend, payment gateway, admin panel, or database schema. All functionality should be simulated on the frontend with mock/static data. Focus on making the final result feel like a real, production-quality ecommerce website specifically designed for this household-products business, rather than a generic ecommerce template.
